# Danar Abdi Manaf Hamid — Portfolio

Personal portfolio website built with Next.js (App Router), React, and TypeScript (strict mode).

**Live:** [https://danar-portofolio.vercel.app](https://danar-portfolio.vercel.app/)

## Tech Stack
- Next.js, React, TypeScript
- Tailwind CSS
- Deployed on Vercel

## Run Locally
npm install
npm run dev

- `npm run build`
- `npm run lint`
